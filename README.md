# 一念成仙 / VampireSurvivors

修仙题材幸存者游戏。移动、自动战斗、升级选词缀、灵根融合与悟道进化，配合局外宗门成长。

## 打开项目

使用 **团结引擎 1.9.3 / 2022.3.62t11** 打开本目录。项目使用团结 `.scene` 文件及序列化格式，不能保证直接用标准 Unity 编辑器打开。

打开 `Assets/Scenes/大厅.scene` 并运行，点击右上角 **修仙 · 养成**，或按 **F3**。大厅已设为构建列表的第一个场景。首次导入会重新生成 Library，耗时取决于本机。

美术、音频、预制体及 `.meta` 均保留。Library、日志、聊天导出、原机编辑器助手缓存不入库；三个引用原机隐藏目录的编辑器助手包已从 manifest 移除，不影响项目游戏脚本。

## 新增的局外循环

- **藏经阁**：五本无属性基础功法免费；其他功法可花灵石或5功法碎片解锁。主修50灵石、辅修20灵石、禁术100灵石；携带三个槽位，同一种基础技能不能重复。
- **炼丹房**：气血、攻击、防御、速度、幸运、暴击永久强化，按 TUTORIAL 10.3 的价格与每次固定效果执行。该节“随机+1~3”与随后固定效果表冲突，本实现采用表格。
- **宗门建设**：悟道台开放悟道/天赋层级，灵脉增加拾取范围，演武场增加攻击；选择出生灵根。设施最多10级，每级花费20×目标等级灵石。
- **悟道树**：术/法/道三线，永久增加攻击/生命/幸运。每两级天赋需要一级悟道台；每级花费10×目标等级灵石及目标等级词缀碎片。已定义的道可用25灵石、3功法碎片解锁。
- **本命法宝**：使用局外统一钱包升阶和精炼，重启仍保留。仙器不再免费升阶。
- **秘境结算**：死亡或返回大厅时转存灵石及两类碎片，清空本局背包，防止重复领取。境界修为实时保存。
- **局内悟道**：满级后从已解锁的对应道中选择，不再自动选第一项；无属性/尚未设计分支保留通用路径。没有已解锁元素道时保持Lv10，回宗门解锁后下局可进化。第二次满级保留原有 R 键神通充能机制。

永久成长在新角色初始化时应用；修改功法后的计划词缀按原有升级系统依次激活。三个槽位均配置常驻功法，不额外引入文档未定义的禁术资源或施法规则。

## 存档与修复

进度位于 `Application.persistentDataPath/cultivation_v1.json`，临时文件写入后替换正式文件，保留 `.bak`。损坏时尝试备份；旧版功法编辑 JSON 继续使用。只编辑运行时属性，不改写基础属性资产。

同时修复死亡面板不出现、重复应用功法叠加攻击/攻速、重复切场景、极高攻速导致冷却为负，以及旧功法存档缺少词缀数组时的异常。
